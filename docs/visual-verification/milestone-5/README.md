# Milestone 5 visual verification

The Playwright supporting-route suite captures full-page desktop (1280×900)
and mobile (390×844) screenshots for `/prislub-zoznam`, `/dakujem`, `/press`,
`/vily`, and `/gdpr` after fonts and public pledge data finish loading.

These routes extend the established React design system rather than copying a
new reference mockup. Review focuses on the sketchbook identity, typography,
paper texture, sticker controls, sharp borders and shadows, responsive
composition, readable tables, accessible placeholders, and absence of page
overflow. The `/vily` screenshots must not expose internal editorial-status
language.
